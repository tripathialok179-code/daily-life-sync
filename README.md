# Daily Life Sync

Welcome to **Daily Life Sync** – a premium, modern, and high-performance productivity application designed to seamlessly organize and synchronize your daily activities. 

## Features

- 📅 **My Tasks**: Categorized daily, weekly, monthly, and yearly goals to keep your productivity high. Archive completed tasks as achievements.
- 📆 **Interactive Calendar**: A holistic overview of your accomplishments and tasks scheduled throughout the month.
- 📝 **Daily Journal**: Capture moments, moods, and thoughts in an elegant, distractions-free journal editor.
- 📋 **My Lists**: Flexible check-lists for your grocery shopping, movie plans, bucket lists, and other custom requirements.
- 🎨 **Accent customization**: Multiple vibrant built-in accent color themes with responsive light and dark system integrations.

## Run Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run in development mode**:
   ```bash
   npm run dev
   ```

3. **Build the production bundle**:
   ```bash
   npm run build
   ```
